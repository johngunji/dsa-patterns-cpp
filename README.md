# DSA Patterns (C++)

A collection of C++ solutions organized by data structure/algorithm pattern, built while practicing common DSA problems.

## Structure
- `Arrays/` — array-based problems (e.g., prefix sums, range sum queries)
- `Hashing/` — hashing-based problems (e.g., subarray sum using prefix sums and hashing)
- `Strings/` — string problems (e.g., longest substring problems)

## Purpose
Practice repository for reinforcing core DSA patterns in C++.
